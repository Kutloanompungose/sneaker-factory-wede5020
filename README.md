Sneaker Factory – Web Development Part 3

1. Project Overview

Sneaker Factory is a responsive e-commerce sneaker website developed as part of the Web Development Part 3 Portfolio of Evidence (POE).

The website allows users to browse sneaker products, search for products, filter products by category, select colours and sizes, add products to a shopping cart and manage a wishlist.

The website uses a modern black, white and red design to create a simple and user-friendly shopping experience.

2. Technologies Used

* HTML5 – Website structure and content.
* CSS3 – Website styling and responsive layout.
* JavaScript – Website functionality, interactivity and form validation.
* GitHub – Version control and source code hosting.
* GitHub Pages – Free website hosting and deployment.

3. Part 3 Functionality

The following JavaScript functionality has been implemented:

* Product search functionality.
* Product category filtering.
* Shopping cart functionality.
* Automatic shopping cart total calculation.
* Wishlist functionality.
* Product colour selection.
* Local storage to remember cart and wishlist items.
* Contact form validation.
* Registration and login demonstration.
* Dark mode functionality.
* Back-to-top button.
* Automatic display of the current year.

6. How to Run the Website

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files are in the same root folder.
4. Open index.html in a browser.
5. Alternatively, use the Live Server extension in Visual Studio Code.
